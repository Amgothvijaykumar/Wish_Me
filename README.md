Welcome to V2! This is a complete reimagining of the birthday greeting project, designed with an engaging, multi-step user experience and a host of modern animations.



## ✨ Features

* **Interactive Multi-Step Reveal:** A playful journey from the intro screen to birthday wishes, a virtual hug, a cake reveal, and a photo memory frame.
* **Enhanced Animations:**
    * **Rising Balloons:** Colorful balloons float up the screen.
    * **Typewriter Text Effect:** The main greeting is typed out for a dramatic effect.
    * **Smooth Card Transitions:** Each screen enters with a soft animated reveal.
    * **Photo Collage Frame:** Four corner photos and a centered memory photo create a keepsake-style finish.
* **Zero Dependencies:** Built with just HTML, CSS, and vanilla JavaScript.
* **Modern & Responsive Design:** Looks beautiful on all devices.
* **Easy to Customize:** Personalize the name, message, and photos in the `index.html` file and the `photos/` folder.

## 🚀 Getting Started

No complex setup is required! You can run this project locally in just a few steps.

### Prerequisites

You only need a modern web browser like Google Chrome, Firefox, or Safari.

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Amgothvijaykumar/Wish_Me.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd Wish_Me
    ```
3.  **Open the file:**
    Simply open the `index.html` file in your web browser. That's it!

***

## 🎮 How to Customize

Personalizing the birthday card is incredibly simple.

1.  Open the `index.html` file in a text editor.
2.  Change the name inside the `<h2 class="name">` tag on the cake page.
3.  Update the wish inside the `<p class="wish-message">` tag if you want a different message.
4.  Replace the images in `photos/p1.jpeg` through `photos/p5.jpeg` if you want a new collage.
5.  Save the file, and your personalized greeting is ready!
